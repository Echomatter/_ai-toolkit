# Architecture

```text
OpenCode Desktop
 |
 |-- Build (customized primary; user-selected model)
 |    |-- Explore (native read-only source-code search)
 |    |-- Researcher (orientation/investigation; read-only on project source)
 |    |-- Worker  (bounded implementation; model bound per child via delegate)
 |    |-- Architect (hard tradeoffs; model bound per child via delegate)
 |    `-- Review  (independent read-only verification)
 |
 |-- Plan (native; user selects explicitly)
 |
 |-- skills: reorient, search-index, sync, model-routing, record-outcome
 |-- tools: content_index, delegate
 |-- native websearch/webfetch
 |-- git + gh
 |-- ~/.agents/skills/*
 `-- ~/.config/opencode/AGENTS.md
      `-- toolkit-managed global workflow block + preserved user content
```

OpenCode owns the execution harness, provider/model plumbing, `/models`, tools, permissions, context management, and child sessions. The toolkit does not duplicate those systems.

Roles and models are separate concerns. A role defines purpose, prompt, permissions, tool access, and delegation topology. User-invoked skills and helpers inherit the model that received the request. Agent-initiated children call the `delegate` tool, which must bind the selected model at execution — selection alone is not execution. The LLM never manually ranks models from memory; `scripts/select-model.ps1` is the deterministic source.

The Desktop app loads the toolkit's Build/Researcher/Worker/Architect/Review definitions through `~/.config/opencode/agents/`. There are no toolkit slash-command wrappers.

The toolkit-managed block in global `AGENTS.md` carries the public catalog, delegation rules, and sparse next-phase recommendation behavior. It is regenerated by `refresh-routing.cmd` and merged without replacing user-authored global instructions.

Scout is not part of the stable dependency surface for this toolkit. External research stays in Build using native web tools.

The global `content_index` custom tool wraps the toolkit-owned Python indexer. It is deterministic retrieval infrastructure, not another model router.
